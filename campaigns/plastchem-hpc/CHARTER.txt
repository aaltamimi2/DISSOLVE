2. FROZEN RECIPE — DO NOT CHANGE ANY OF THIS
=====================================================================
openCOSMO-RS 24a is parameterised at exactly this level of theory. Changing it makes the
partition coefficients wrong by an unbounded amount.

  geometry optimisation : BP86 / def2-TZVP(-f)   ! OPT ... TightSCF
  COSMO single point    : BP86 / def2-TZVPD via COSMORS(Water), writes .orcacosmo
  charge/multiplicity   : * xyz 0 1   (neutral singlet; this is why charged species and salts
                                       were filtered out of the input set)
  parallelism           : serial. NO %pal.
  memory                : %maxcore 1500
  conformers            : ONE. RDKit ETKDG + MMFF ranks them; the lowest is the one DFT'd.
                          Ensembles are not the default and are not authorised here.
  identity              : InChIKey computed after optimisation
  ORCA version          : 6.1.1 (see section 4)

The reference implementation of this recipe is in the READ-ONLY files
  ~/dissolve-v12-builder-1/src/dissolve/cosmo_logp.py
  ~/dissolve-v12-builder-1/scripts/cosmo/run_orca_stage.py
Read them for the exact input-file construction. Copy what you need into ~/plastchem-euler/.
